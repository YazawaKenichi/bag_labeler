# bag_labeler

rosbag2 (`.db3`) の映像とセンサの時系列グラフを見ながらラベル区間を付け、
`elapsed, データ軸..., label` 形式の CSV データセットを作る GUI ツール。

ROS を起動する必要はなく、[rosbags](https://gitlab.com/ternaris/rosbags) で `.db3` を直接読む。

## セットアップ

```bash
pip install -r requirements.txt
```

## 起動

```bash
./launch.bash              # launch.bash の TARGET_DIR 以下の rosbag を処理
./launch.bash <ディレクトリ>  # 指定したディレクトリ以下を処理
```

どこから実行してもよい。指定ディレクトリ以下を再帰的に探索し、`metadata.yaml` と `.db3` を含む
ディレクトリを rosbag として一覧に出す。終了はウィンドウを閉じるか、ターミナルで Ctrl+C。

## 画面

| 場所 | 内容 |
|---|---|
| 左 | rosbag 一覧 (`✓` は CSV 保存済み) |
| 中央上 | 映像 |
| 中央 | プロット (折り畳み可)。左欄に表示中フレーム時点の値、右に波形 |
| 中央下 | シークバー、タイムライン、ラベル区間一覧 |
| 右 | 設定と、フィールドのツリー (左の列: CSV に出す列 / 右の列: プロットに出す信号) |

プロットとタイムラインの表示:

- 色付きの帯: ラベル区間
- 赤線: 停止ボタン (既定 `/joy` の `buttons[5] ≥ 0.5`) が押された時刻
- 緑線: odom で停止した時刻 (`/odom` の速度が 0.05 以上から 0.005 未満になった時刻)
- 黄線: 表示中のフレーム

プロット・タイムラインはクリック/ドラッグでシークできる。プロットの「表示幅」で拡大表示できる。

## キー操作

| キー | 動作 |
|---|---|
| ← / → | 1 フレーム移動 (Shift で 10 フレーム) |
| Home / End | 先頭 / 末尾 |
| Space | 再生 / 一時停止 |
| Enter | 現在フレームからラベル区間を開始 |
| E | 選択中 (未選択なら最後) の区間の終了を現在フレームにする |
| S | 映像でロボットが止まったフレームで押すと、odom の停止時刻に合うよう映像オフセットを設定 |
| Delete | 選択中 (未選択なら最後) の区間を削除 |
| Ctrl+S | CSV 保存 |

## ラベリング手順

1. bag を選び、映像でロボットが止まったフレームで **S** を押して映像オフセットを合わせる (後述)
2. チェーンが段差に接触したフレームで **Enter**
   - 接触 〜 odom 停止 が `label 1`
   - odom 停止 〜 bag 末尾 が `label 2` (接触したまま停止している状態)
3. うまく区切れない bag は **E** で label 1 の終了を手動で直す (label 2 の開始は連動する)
4. **Ctrl+S** で CSV 保存

区間の終了の決め方は右の設定「区間の終了」で変えられる。

| 設定 | 動作 |
|---|---|
| odom 停止まで → 以降 label 2 (既定) | 上記の手順 |
| 手動 (E キー) | E を押すまで bag 末尾まで |
| 停止ボタン | 停止ボタンが押された時刻まで |
| odom 停止 | odom の停止時刻まで |

区間は `開始 ≤ t < 終了` として扱うので、連続する区間で行が重なることはない。
区間が重なった場合は一覧で後ろにある区間のラベルが優先される。

### 映像オフセット

カメラの映像は実際より遅れて記録される (USB カメラの取り込みが追いつかず、V4L2 のバッファに
古いフレームが溜まるため。タイムスタンプは撮影時刻ではなく読み出し時刻)。
映像オフセット [s] だけ映像を前にずらしてデータと合わせる。

- S キーで、表示中フレームを「映像でロボットが止まった瞬間」とみなして odom の停止時刻に合わせる
- 右の設定から手入力もできる
- bag ごとに保存され、新しく開く bag には直前の値が初期値として入る
- オフセットを変えると、映像を見て決めた区間の開始・手動の終了も一緒にずれる

## 出力

すべて db3 と同じディレクトリに保存する。

| ファイル | 内容 |
|---|---|
| `<bag名>_dataset.csv` | データセット |
| `<bag名>_labels.json` | ラベル区間と映像オフセット。変更のたびに自動保存され、bag を開き直すと復元される |

起動時に指定したディレクトリには `.bag_labeler.json` (選択した列・プロット・停止ボタン等の設定) を保存する。

### CSV の形式

```
elapsed,/hx711/raw/data,/cmd_vel/linear.x,...,label
0.065755,286211,,...,0
```

- 行: 基準トピック (既定 `/hx711/raw`) を受信した時刻ごとに 1 行
- `elapsed`: bag 先頭からの秒
- データ列: `<トピック>/<フィールド>`。他のトピックはその時刻での最新値 (直前値保持)。
  まだ一度も受信していなければ空欄
- `label`: 区間外は 0
- 時刻はすべて bag の記録時刻 (header.stamp ではない)

数値として扱わないトピック (`/tf`, `/rosout`, `/diagnostics` など) は列の候補に出ない。
要素数が 256 を超える配列は展開しない。

### 学習で使うとき

`label 2` は学習時に用途に合わせて変換する。

```python
df = pd.read_csv('xxx_dataset.csv')
df = df[df.label != 2]                 # 走行中の接触を検出する 2 値分類
df['label'] = df.label.replace({2: 1}) # 接触しているかを判定する 2 値分類
```

- `elapsed` は特徴量としてそのまま使わない (どの bag も後半に label 1, 2 があるため、時刻だけで当たってしまう)。
  `x.diff() / df.elapsed.diff()` のように変化率を求めるのに使う
- 学習・テストの分割は行単位ではなく bag 単位で行う
